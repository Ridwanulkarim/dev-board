Question-1: What are the different ways to select an element in the DOM?

We can select elements using getElementById(), getElementsByClassName(), getElementsByTagName(), querySelector(), and querySelectorAll().

Question-2: What is the difference between innerHTML, innerText, and textContent ?

innerHTML returns and parses HTML tags within an element, innerText returns only the human-readable text respecting CSS styling and visibility, and textContent retrieves all text content including hidden elements and scripts as raw text.

Question-3: What is event delegation in the DOM?

Event delegation is a pattern where you attach a single event listener to a common parent element rather than attaching listeners to multiple individual child elements. It leverages the event bubbling mechanism to handle events on current and dynamically added children efficiently.

Question-4: What is event bubbling in the DOM?

Event bubbling is a propagation mechanism in the HTML DOM where an event fired on a nested child element "bubbles up" through its ancestors in the DOM tree until it reaches the document root, unless stopped using event.stopPropagation().

Question-5: How do you create, add, and remove elements using JavaScript?

We can create elements with document.createElement(tagName), insert them into the DOM using parent.appendChild(node) or parent.append(), and remove them using node.remove() or parent.removeChild(node).
