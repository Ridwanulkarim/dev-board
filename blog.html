Question-1: What are the different ways to select an element in the DOM?

There are several primary methods to select elements in the Document Object Model (DOM):

  • document.getElementById('id'): Selects a single element by its unique ID.
  • document.getElementsByClassName('class'): Selects all elements with the given class, returning an HTMLCollection.
  • document.getElementsByTagName('tag'): Selects all elements matching the tag name (e.g., 'p', 'div'), returning an HTMLCollection.
  • document.querySelector('selector'): Returns the first matching element using standard CSS selector syntax.
  • document.querySelectorAll('selector'): Returns all matching elements as a static NodeList.

Question-2: What is the difference between innerHTML, innerText, and textContent ?

The differences are as follows:

  • innerHTML: Gets or sets the HTML markup contained within an element, parsing and rendering HTML tags into elements.
  • innerText: Gets or sets the human-readable visible text inside an element. It is style-aware (it ignores text hidden by CSS like display: none) and triggers layout reflow.
  • textContent: Gets or sets the complete raw text of the element and all its descendants, including hidden elements and script contents, without parsing HTML or triggering expensive reflow.

Question-3: What is event delegation in the DOM?

Event delegation is an efficient pattern in JavaScript where a single event listener is attached to a parent container instead of attaching separate listeners to multiple child elements.

Because of event bubbling, events triggered on child elements bubble up to the parent. By inspecting event.target, the parent listener can identify the exact child clicked. This saves memory and automatically handles dynamically created elements.

Question-4: What is event bubbling in the DOM?

Event bubbling is the default phase of event propagation in the DOM hierarchy where an event triggered on a nested child element "bubbles up" through its ancestors in the DOM tree (child → parent → body → html → document → window).

If any ancestor has an event listener for that event type, it will be executed during the bubbling phase unless explicitly prevented using event.stopPropagation().

Question-5: How do you create, add, and remove elements using JavaScript?

  • Create: Use document.createElement('tagName') to create an element in memory.
  • Add/Insert: Use parentElement.appendChild(childNode) or parentElement.append(childNode) to insert the element into the DOM.
  • Remove: Call element.remove() directly on the element, or call parentElement.removeChild(childNode) from its parent.
