১. প্রজেক্ট পরিচিতি ও ফাইল আর্কিটেকচার (Project Overview)

index.html মূল ড্যাশবোর্ড, ৬টি টাস্ক কার্ড গ্রিড এবং রিয়েল-টাইম Activity Log সাইডবার।

js/theme.js থিম কন্ট্রোলারে ক্লিক করলে বডির ব্যাকগ্রাউন্ডে র‍্যান্ডম প্যাস্টেল কালার সেট করে।

৪. জাভাস্ক্রিপ্ট ফাইলগুলোর কাজের ধারা (JavaScript Logic)

১. time.js — ডাইনামিক লাইভ ডেট

const date = new Date();
const dayName = date.toLocaleDateString("en-US", { weekday: "short" }) + " ,";
const month = date.toLocaleDateString("en-US", { month: "short" });
const day = date.getDate().toString().padStart(2, "0");
const year = date.getFullYear();
document.getElementById("day").textContent = dayName;
document.getElementById("full-date").textContent = `${month} ${day} ${year}`;

বিল্ট-ইন Date() অবজেক্ট ব্যবহার করে ব্রাউজারের সিস্টেম ক্লক থেকে লাইভ দিন ও তারিখ তৈরি করা হয়।

২. theme.js — র‍্যান্ডম কালার জেনারেটর

function getRandomLightColor() {
    const letters = "ABCDEF";
    let color = "#";
    for (let i = 0; i < 6; i++) {
        color += letters[Math.floor(Math.random() * letters.length)];
    }
    return color;
}
themeButton.addEventListener("click", () => {
    document.body.style.backgroundColor = getRandomLightColor();
});

উচ্চমানের হেক্স লেটার (A-F) ব্যবহারের ফলে প্রতিটি কালার সফট/প্যাস্টেল শেডে তৈরি হয়, যা টেক্সট পড়ার সুবিধা অক্ষুণ্ণ রাখে।

৫. ভাইভাতে জিজ্ঞেস করার মতো মূল প্রশ্ন ও উত্তর (Top Viva Q&A)

প্রশ্ন ১: DOM কী?

উত্তর: DOM (Document Object Model) হলো একটি প্রোগ্রামিং ইন্টারফেস, যা কোনো HTML ডকুমেন্ট লোড হওয়ার পর ব্রাউজারে একটি অবজেক্ট ট্রির (Tree of Objects) মতো তৈরি করে। এর ফলে জাভাস্ক্রিপ্ট দিয়ে পেজ রিলোড না করেই লাইভ HTML উপাদান, টেক্সট ও CSS স্টাইল পরিবর্তন করা যায়।

প্রশ্ন ২: DOM-এ এলিমেন্ট সিলেক্ট করার উপায়গুলো কী কী?

  • document.getElementById('id') — নির্দিষ্ট ID বিশিষ্ট ইউনিক এলিমেন্ট সিলেক্ট করে।
  • document.getElementsByClassName('class') — ক্লাসের সব এলিমেন্ট নিয়ে একটি HTMLCollection দেয়।
  • document.getElementsByTagName('tag') — ট্যাগের নাম অনুযায়ী এলিমেন্ট সিলেক্ট করে।
  • document.querySelector('selector') — প্রথম ম্যাচ করা CSS সিলেক্টর রিটার্ন করে।
  • document.querySelectorAll('selector') — ম্যাচিং সব এলিমেন্টকে একটি স্ট্যাটিক NodeList হিসেবে দেয়।

প্রশ্ন ৩: innerHTML, innerText এবং textContent এর পার্থক্য কী?

  • innerHTML: ভেতরের HTML ট্যাগসহ কনটেন্ট পার্স ও রেন্ডার করে।
  • innerText: শুধুমাত্র স্ক্রিনে দৃশ্যমান (visible) টেক্সট রিটার্ন করে। এটি CSS চেনে (যেমন: display: none টেক্সটকে বাদ দেয়) এবং ব্রাউজারে reflow ঘটায়।
  • textContent: লুকানো অংশ ও স্ক্রিপ্টসহ সমস্ত র-টেক্সট দ্রুত ফিরিয়ে দেয়। এটি ব্রাউজার পারফরম্যান্সের দিক থেকে সবচেয়ে ফাস্ট।

প্রশ্ন ৪: Event Delegation ও Event Bubbling কী?

  • Event Bubbling: কোনো চাইল্ড এলিমেন্টে ক্লিক করলে সেই ইভেন্টটি তার চাইল্ড থেকে প্যারেন্ট, বডি হয়ে উইন্ডো পর্যন্ত বুদবুদের মতো ওপরের দিকে ছড়াতে থাকে। একে থামাতে event.stopPropagation() ব্যবহার করা হয়।
  • Event Delegation: প্রতিটি চাইল্ডে আলাদা লিসেনার না বসিয়ে তাদের প্যারেন্ট এলিমেন্টে একটিমাত্র ইভেন্ট লিসেনার বসিয়ে event.target দিয়ে হ্যান্ডেল করার কৌশল। এতে মেমরি বাঁচে এবং ডায়নামিক এলিমেন্ট সহজে পরিচালনা করা যায়।

প্রশ্ন ৫: কীভাবে জাভাস্ক্রিপ্ট দিয়ে উপাদান তৈরি, যোগ ও মুছে ফেলা হয়?

  • Create: document.createElement('div')
  • Add: parent.appendChild(node) অথবা parent.append(node)
  • Remove: সরাসরি node.remove() অথবা প্যারেন্ট থেকে parent.removeChild(node)
